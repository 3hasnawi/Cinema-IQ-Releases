# Cinema iQ — إصدارات Android TV

هذا المستودع العام مخصص لملفات APK الرسمية ومعلومات تحديث تطبيق **Cinema iQ** فقط. السورس محفوظ في مستودع خاص.

[أحدث إصدار منشور](https://github.com/3hasnawi/Cinema-IQ-Releases/releases/latest)

لا يوجد إصدار جديد منشور من إعداد المستودع حتى الآن. يجب تثبيت أول نسخة تدعم التحديث من GitHub مرة واحدة؛ النسخة 4.2 والنسخ الأقدم لا تحتوي هذا الربط.

## طريقة التحديث

التطبيق يفحص أحدث إصدار مستقر، ويعرض التحديث في الإعدادات. التنزيل والتثبيت يحتاجان موافقة المستخدم. لا يحتاج الوصول إلى هذا المستودع إلى حساب GitHub.

## للمطور / مالك التطبيق

لكل Release ارفع ملف APK وملف `update.json` معاً. يجب أن يحتوي JSON على:

- `packageName`: الحزمة `com.cinemaplus.rebuilt`.
- `versionCode`: الرقم الصحيح من APK، أكبر من الإصدار المثبت.
- `versionName`: اسم الإصدار من APK.
- `minSdk`: الحد الأدنى من APK.
- `apkUrl`: رابط ملف APK داخل Release في هذا المستودع.
- `sha256`: بصمة SHA-256 للملف الموقّع نفسه.
- `releaseNotes`: وصف التغييرات، اختياري.

التطبيق يرفض الحزمة أو التوقيع المخالفين للنسخة المثبتة. لا تغيّر مفتاح التوقيع بين الإصدارات.

لا ترفع السورس، ملفات keystore، كلمات المرور أو مفاتيح خدمات المحتوى إلى هذا المستودع العام. البناء والنشر لا يتمان تلقائياً عند تعديل السورس؛ تشغيل الإصدار يتطلب أمر المالك.
